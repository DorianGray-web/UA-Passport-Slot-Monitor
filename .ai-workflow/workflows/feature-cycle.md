# Feature Cycle

1. Researcher gathers evidence and unresolved questions.
2. Spec Creator writes or refines one specification under `specs/`.
3. Human approves scope and open questions.
4. Implementation Planner writes one plan under `plans/`.
5. Implementer completes one bounded slice at a time.
6. Verifier checks every acceptance criterion and writes a report.
7. Workflow Retro records only reusable lessons under `insights/`.

A failed verification returns to planning or implementation; it does not silently widen scope.
