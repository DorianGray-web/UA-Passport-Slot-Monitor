# Documentation Language Flags

This directory contains local 4×3 flag icons used only by documentation
language selectors. Do not hotlink flag assets or duplicate them elsewhere.

The current selector includes English (`gb.svg`), Ukrainian (`ua.svg`), and
Russian (`ru.svg`). Future languages can be added by copying the corresponding
4×3 SVG into this directory and adding one flag entry to each selector; no
layout redesign is required.

The SVG files are copied from `flag-icons` version 7.5.0 by Panayiotis
Lipiridis and contributors. The package is distributed under the MIT License;
see [LICENSE.flag-icons](LICENSE.flag-icons).
