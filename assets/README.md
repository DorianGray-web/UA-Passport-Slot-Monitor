# Project Assets

This directory is the shared asset library for project documentation, GitHub
Pages, the future website, and the application UI. Shared assets belong only
in `assets/` and must not be duplicated in other directories.

## Directory policy

### `flags/`

Documentation language navigation icons. Add a new local SVG and one language
entry to each selector when another documentation language is introduced.

### `logos/`

Official project branding assets.

### `backgrounds/`

UI backgrounds and visual themes for the future web interface.

### `diagrams/`

Architecture and workflow diagrams.

### `media/`

Shared documentation images, GitHub social preview images, UI illustrations,
release graphics, and other static media resources.
